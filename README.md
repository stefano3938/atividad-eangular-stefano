# Ford

Projeto Angular desenvolvido para o Dashboard da Ford.

## Instalação

```bash
npm install
```

## Servidor de Desenvolvimento

Para rodar o servidor local, execute:

```bash
npm start
```
Acesse `http://localhost:4200/`. A aplicação recarregará automaticamente se você alterar qualquer um dos arquivos fonte.

## Compilação

Para compilar o projeto, execute:

```bash
npm run build
```
Os artefatos compilados serão armazenados no diretório `dist/`.
